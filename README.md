## Recent projects

This repositories are projects I developed for personal use and I though they might be useful to others.

* **[Personarum](https://github.com/jasharioktavio/Personarum)**: Full-stack application for centralized management of personal profiles, documents and reusable document templates. Built around a Java/Spring Boot backend with a modern web frontend and designed as a practical solution for document and profile management.
* **[FE-Scraper](https://github.com/jasharioktavio/FE-Scraper)**: .NET tool for parsing Italian electronic invoices and extracting structured data from FatturaPA XML files. Part of my experimentation with tools for automating and simplifying electronic invoice management.
